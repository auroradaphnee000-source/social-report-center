# Social Report Center

Facebook / Instagram / LinkedIn 自然内容周期报告应用，提供 Meta 后台同步、Word 生成与独立 POPO 交付。

## 两个测试版本

当前快照：**1.5.7**。仓库通过 `v1.5.6` 和 `v1.5.7` 标签区分版本，`main` 为 1.5.7。

- **1.5.6**：本次优化之前的本地逻辑重建基线。不是从生产镜像导出的快照，详见 `PROVENANCE.md`。
- **1.5.7**：Facebook 相同日度响应复用、每个不超过 30 天的日期段进度、默认 1200 秒同步总时限。总时限在网络请求和分段处检查，进行中的 I/O 退出后生效。

这个 Public 仓库供查看、下载和管理员对比测试，暂不附加开源许可证。它不提供生产授权、客户数据或一个已部署的在线服务。

## 本地运行

需要 Python 3.12。建议先创建虚拟环境，再运行：

```sh
pip install -r requirements.txt
python -m uvicorn webapp.app:app --host 127.0.0.1 --port 8090
```

打开 `http://127.0.0.1:8090`；健康接口为 `/api/health`。初次运行未提供 Meta / POPO 配置时，集成状态应显示未配置。运行程序不自动读取 `.env`；请通过系统环境变量或下述 Compose 配置注入。

## 容器测试与持久化

```sh
cp .env.example .env
docker compose up --build -d
```

服务仅映射到本机 `127.0.0.1:8090`。Compose 将命名卷挂载到 `/app/runtime`，数据库、输入、报告与 Fabric HOME 都放在该目录。普通容器重建复用该卷；删除卷会删除其数据。生产共享访问需配置自己的身份验证网关。

此通用测试容器不包含内部 Fabric CLI。验证真实 POPO 交付时，由管理员在其受支持运行环境中提供 CLI、内网出口及授权；不要上传这些内容到仓库。

## 测试

```sh
pip install -r requirements-dev.txt
python run_tests.py
```

测试使用隔离临时目录、模拟 Meta 请求，并关闭 POPO 自动刷新。公开测试集不依赖客户报告、截图或真实凭证；省略的两个旧客户年报测试见 `PROVENANCE.md`。GitHub Actions 对提交运行相同测试。

## 管理员真实流程验收

1. 在隔离测试环境配置自己的 Meta 应用、回调与测试页面授权。选择超过 30 天的日期范围，检查 1.5.7 是否显示指标、日期、段数和持续变化的进度。
2. 等待真实同步结束，确认结果保存后才供报告使用；比较概览和月度序列，缺失数据应保持缺失。
3. 核对 `/api/health` 的 service、version、队列和集成状态。配置布尔值不能代替真实同步成功。
4. 在受支持的 POPO 环境验证 Word 生成、原生正文、附件及独立重试。
5. 替换已有生产容器前，先确认平台运行目录、环境变量、加密密钥和访问密码的保留方式；备份并在重建后核对已有记录与文件。

本仓库的通用命名卷配置，不能证明其他托管平台的 `svc.deploy` 会保留旧数据。1.5.7 生产部署与生产真实流程验收尚未完成。

## 配置

只在测试环境注入变量值，不提交 `.env`。变量名和非敏感默认项见 `.env.example`。Meta token 加密密钥需由管理员在其环境中安全生成；POPO 目标空间由管理员自行设置。
